# Archive

`ablation_tables/ablation_tables.py` and `ablation_tables.md` are an earlier table generator and its output. They
cover only the first-stage results (constant learning rate, legacy best-test-loss metric) and expect an older folder
layout, so they do not run from this repository as is. They are superseded by `analysis/stats.py`, which reproduces
every number in the report, and are kept only for the record.
